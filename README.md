## Installation
```npm install```

## Run locally
```npm run dev```

## Table-tennis authoring
Use the toolbar at the top of the table-tennis scene to show extensions, manage
visualizations, manipulate actors, or edit their characteristics. The
Selection button switches between clicking a visible actor and choosing from a
list. For extensions, the list contains non-extension actors; for manipulation
and characteristics, it contains displayed extensions. Visualization selection
includes non-extensions and displayed extensions. Visualizations are configured on
the existing relationships between actors; use Visualizations to add, edit, or
remove them. Removing one restores its relationship parameters to their defaults.
